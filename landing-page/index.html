Frequently Asked Questions

Is Snippet Bubbles really free?

Yes—there are no subscriptions or ads. AI features are subject to fair-use request limits so the service remains available and abuse-resistant.

How does the AI work?

Snippet Bubbles uses a built-in AI service to generate, explain, and convert code—no external API key required. When you request an AI action, the prompt, code, or snippet text you include is sent to that service to create the response. We retain only operational metadata such as action type, time, character counts, outcome, and quota use; we do not store those prompts or snippets in AI telemetry.

Can I use it offline?

Your local snippet library remains available offline after installation. Cloud backup, syncing, and AI requests need an internet connection when you choose to use them.

What languages are supported?

We support 40+ programming languages including JavaScript, Python, Java, C++, Go, Rust, SQL, HTML, CSS, and more. If we're missing one, let us know!

Is my data safe?

Your library is local-first. Optional sign-in enables cloud backup and sync, while AI actions necessarily send the content you choose to include to the built-in AI service. We do not sell personal data, and our AI telemetry intentionally excludes prompt, code, snippet content, and raw IP addresses. Read the AI data-use notice before using AI with sensitive material.

Can I sync across devices?

Yes. Optional sign-in enables cloud backup and device sync. Offline edits are preserved; if two devices change the same item, the app keeps the conflicting versions for review rather than silently throwing one away.
